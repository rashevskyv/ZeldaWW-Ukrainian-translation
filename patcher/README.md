# The Legend of Zelda: The Wind Waker (GameCube) — патчер українського перекладу

Патчер завантажує з цього репозиторію актуальні файли перекладу і збирає з вашого образу новий перекладений образ.
Оригінальний образ патчер лише читає і не змінює.

## Вимоги

1. Власний образ гри **GameCube, USA** (ID `GZLE01`, ревізія 0) у форматі **`.iso`** або **`.rvz`** з будь-яким стисненням (також `.gcz`, `.wia`, `.ciso`).
2. Вільне місце на диску: близько 4,5 ГБ.
3. Інтернет для завантаження файлів перекладу.
4. Windows: `WindWaker_Patcher.exe`. macOS / Linux: Python 3.10+, **Wine** і команда `python3 patcher.py`
   (утиліти `gcr.exe` і `DolphinTool.exe` з теки `soft` запускаються через Wine).

## Покрокова інструкція

1. Покладіть свій образ гри у теку `ISO` поруч із патчером.
2. Запустіть `WindWaker_Patcher.exe` (або `python3 patcher.py`).
3. Патчер:
   - завантажить актуальні файли перекладу з GitHub;
   - розпакує стиснений образ у тимчасовий `.iso` вбудованим DolphinTool (оригінал не змінюється);
   - перевірить ID гри і `main.dol`; якщо образ інший, попередить і спитає, чи продовжувати;
   - розпакує образ, замінить тексти, шрифти й `main.dol` на українські;
   - збере новий образ `ISO\<назва>_UA.iso` і видалить тимчасові файли.
4. Після напису «Готово!» натисніть Enter.

## Результат

`ISO\<назва>_UA.iso` — запускайте в Dolphin або на GameCube / Wii (Nintendont).

Для BlueWake (ПК-порт) цей образ не підходить: BlueWake приймає лише оригінальний `main.dol`.
