# Прохід роботи

Сценарій збірки вибирає новіший збережений спільний BMG-архів у GC та сімейному проєкті. Різний вміст з однаковим часом збереження зупиняє роботу. Усі family BMG-архіви надходять у GC staging. HD-only повідомлення беруться з сімейного проєкту.

GC і HD збираються окремо. Нові build-папки копіюються в сусідні тимчасові каталоги до заміни. Заміна обох проходить транзакційно. Помилка чи переривання відновлює попередні папки. Між процесами діє коротке блокування. Перед GC build сценарій просить закритися тільки BlueWake з налаштованого шляху. Збереження не перериваються примусово.

Перед публікацією GC диск має відповідати GZLE01, GC magic і SHA1 оригінального main.dol. Це перевіряє вимоги BlueWake до диска.

`publish_translation.py` створює xdelta-патч для SwitchWaker ISO та патчі файлів Cemu graphic pack. Маніфест містить відносні шляхи й SHA256 джерела, цілі та патча. Пакунок містить `rules.txt`, але не містить повних дисків, ігрових файлів, виконуваних файлів, ключів чи збережень. `--prepare-only` не змінює Git index. BAT публікує тільки після чистої перевірки репозиторію й точного збігу origin.

## Перевірки

У Windows пройшли 20 тестів. Незалежний запуск Sol у WSL: 17 успішних, 3 пропуски залежних від Windows перевірок. Пройшли Ruff, `py_compile` та `git diff --check`.

Фінальна реальна збірка створила GC ISO та HD graphic pack, SDCafiine і SwitchWakerHD overlay. Перевірено повний шлях `play bluewake` з робочої теки `C:\Windows\System32`. BlueWake v0.10.0 показав український вступ. Профіль перевірки та карта пам’яті були окремими від користувацьких.

Кадр перевірки: `E:\Emulators\RomHacking\ZELDA\Wind Waker\_build_proof\final_game\ukrainian_prologue.png`. Оригінальні BAT-файли GC/HD збігаються з початковими SHA256.

Пакунок `patches/` має розмір 2 174 053 байти: два xdelta, правила Cemu, інструкція й маніфест. Обидва патчі накладено на справжні оригінали у тимчасовій теці. SHA256 відновлених файлів збіглися з готовими збірками. Перевірка публікації охоплює fetch URL та всі фактичні push URL.

Запуск на фізичних Switch/Wii U та повне проходження гри не перевірялися. Рендеринг Dolphin/Cemu повторно не перевірявся; їхні збірки й BAT-команди перевірено.
