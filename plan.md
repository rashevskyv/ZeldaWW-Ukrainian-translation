# План

Пакет реалізовано та незалежно схвалено. Реальні збірки й декодування патчів перевірено.

- Підготувати GC та HD збірки у тимчасовій теці.
- Вибирати новіший збережений спільний BMG-архів; однаковий час із різним вмістом вважати конфліктом.
- Перевіряти GC диск до заміни build-папок.
- Перемикати збірки транзакційно та блокувати паралельні запуски.
- Зібрати translation-only патчі й маніфест SHA256.
- Дати окремий режим підготовки та явний BAT для публікації у правильний Git remote.
- Перевірити unit-тести, xdelta round-trip, BAT-входи та відмови до Git-змін.
